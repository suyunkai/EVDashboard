# 仪表工坊 · EVDashboard

[English](README.md) | **简体中文**

![EVDashboard — 适用于单颗 Antora 1000 芯片主机的镜像、提示音与预设管理](docs/images/evdashboard-banner.svg)

适用于 **单颗 Antora 1000 芯片主机**的 Android 应用，提供仪表 CP 镜像备份、检查与受控修改，以及实际仪表提示音的读取、替换和音量管理。

[下载应用](https://github.com/suyunkai/EVDashboard/releases/latest) · [功能介绍](#功能介绍) · [界面预览](#界面预览) · [开始使用](#开始使用) · [免责声明](#免责声明) · [从源码构建](#从源码构建)

> [!WARNING]
> **仅适用于单颗 Antora 1000 芯片主机。** 芯片相同不代表固件兼容，分区和镜像结构仍须通过应用检查。
>
> **本软件可改写仪表 CP 分区镜像。** 镜像不兼容、操作中断、断电或固件异常等问题，均可能造成严重后果，包括仪表或车机无法使用，以及需要自费维修。替换或静音提示音也可能影响安全提醒。
>
> **使用风险及一切后果由用户自行承担。** 请保留独立备份并准备恢复方案，操作期间保持供电稳定，避免 OTA 更新。请遵守所在国家或地区的法律法规与交通规则，使用前阅读[免责声明](#免责声明)。

## 功能介绍

| 功能 | 可以做什么 |
| --- | --- |
| 镜像备份 | 识别当前 CP 槽位，完整导出镜像，核对摘要并分类保存。 |
| 镜像修改 | 导入兼容镜像，独立选择 SSH 自启动及 root 密码清除，保留源文件并生成新镜像。写入复核页显示所选镜像检测出的 SSH 和 root 密码配置；该状态描述镜像配置，不代表实时连接状态。 |
| 镜像写入 | 复核候选镜像，仅写入当前 CP rootfs 槽位，并完整回读校验。 |
| 仪表提示音 | 读取 CP 实际 WAV 资源，分类滚动浏览声音卡片，点击弹窗进行试听、替换、还原和导出。 |
| 内置预设 | 在「预设音效」选择内置音效套装，按分类勾选（支持全选 / 全不选）并逐个试听，点击「应用」写入「实际音效」，之后可单独调整每个声音的音量；「应用并写入 CP」会同时切换车机。 |
| 独立音量 | 原声或替换音频均可调整为 **0%（静音）至 200%**；生成独立派生文件，保留原声和替换源。 |
| 预设与分享 | 最多 **5 个命名预设**，配置与音频打包 ZIP 导入导出，支持单个声音导出。 |
| 启动自动覆盖 | 开机、快速启动、STR 唤醒或打开应用后，核对配置地址、原声摘要与当前资源状态后恢复已配置覆盖，默认关闭。 |
| 操作界面 | 中英切换、紧凑声音弹窗、预设卡片、宽屏镜像选择与配置双列，以及任务计时和进度。 |

镜像处理工具随 APK 提供，安装后无需联网下载处理组件；声音管理需要与 CP 系统建立本地连接。

## 开始使用

1. **确认兼容并准备恢复。** 核对**单颗 Antora 1000 芯片主机**、Android 11 及以上、已授权 root 权限、稳定供电及足够空间。镜像操作全程保持应用前台，避免休眠和 OTA 更新。
2. **安装并授予权限。** 从发行页下载并核对 APK 摘要，安装后授予所需 Android 文件访问权限。镜像操作需独立 UID 0 权限；声音操作需可连接的 CP SSH 服务，并成功以 root 登录。
3. **先备份，再修改。** 在仪表工坊按“识别与备份 → 选择与修改 → 校验与写入”操作。持久修改前，将有效备份另存到独立介质。外部镜像检查通过不等于可以安全写入。
4. **逐项确认声音配置。** 连接 CP、读取目录并点击声音卡片，选择替换文件和/或调整音量，再选择本机保存或明确保存并应用。开启自动恢复前检查所有规则，必要时在系统设置中允许后台运行。

> [!NOTE]
> **镜像写入是持久修改，声音修改使用临时资源覆盖。** 声音覆盖不刷写 rootfs，CP 运行环境重置后需重新应用。导入声音 ZIP 只更新本机配置，不会立即改变 CP 声音。

## 声音使用说明

- **分类浏览。** 常用、警报、雷达、低速、参考、诊断分类采用固定尺寸卡片，上下滚动查看更多；状态标签呈现替换及音量设置，具体操作集中在弹窗中。
- **源文件保持不变。** 替换文件与音量是独立配置项。`100%` 为所选源文件音量，`200%` 约为 +6 dB，并使用平滑限幅。调节时重新生成派生文件，不反复叠加修改源文件。
- **关联素材统一编辑。** 一张卡片可包含多个关联音频，切换素材会保留本次草稿；关闭放弃未保存内容，保存时统一提交卡片草稿，“保存并应用”应用该卡片的修改。
- **试听与导出。** 支持原声、替换源及调音后声音试听。单音导出可选择原声、CP 当前声音、配置声音及未调音替换源，具体取决于可用素材。
- **预设切换。** 命名保存最多 5 个模板，可仅载入或载入并应用。ZIP 同时包含规则、音量、源摘要和引用音频文件。
- **留意共用素材。** 一个文件可能影响多个提醒事件；低速提示音可能共用主辅轨并随车速混音，单文件试听不等于车辆最终输出。映射未确认的参考、诊断素材只允许试听和导出。
- **短音试听处理。** 不足 0.5 秒的声音仅在本机试听缓存增加 600 ms 起始缓冲并重复 3 次；导出和实际覆盖不会增加缓冲或重复，保留配置对应的音频样本与音量。

## 兼容与操作边界

<details>
<summary><strong>镜像兼容条件与写入检查</strong></summary>

- 镜像操作需通过已授权 `su`，或用户开启并授权的本机 `127.0.0.1:5555` ADB 取得 UID 0。应用不会自动执行 `adb root`、重启 adbd 或替换授权。
- `/proc/boot_slot` 必须明确返回 `cp:a` 或 `cp:b`，对应 `cp_rootfs_a` / `cp_rootfs_b`，不使用 Android A/B 槽位猜测 CP 槽位。
- 支持完整 **1 GiB、单 rootfs 载荷的 FIP**；EROFS 偏移与块大小均为 4096，兼容特性为 `1`，不兼容特性为 `0`。
- 仅修改已识别的 Dropbear socket、preset 与账号文件结构。锁定账号、掩码/覆盖配置及未知结构拒绝自动修改。
- 写入要求存在匹配的本机备份基线，逐文件差异只能是允许的 SSH/密码变更或其逆向恢复。不要跨车辆或跨固件版本混刷。
- 写入前重新检查槽位、启动会话、容量、源与候选摘要、挂载及 holders。只写当前 CP rootfs，之后全量回读并逐字节、逐摘要比较，同时核对另一槽与元数据未改变。
- 不自动重启、切槽或重试失败写入。结果未知的中断任务必须先人工核验。
- 默认拒绝同内容重复写入；可选的同内容重写测试需要额外确认，不带来功能升级。

**校验或回读通过，不保证能够启动、成功恢复或自动 A/B 回退。**

</details>

<details>
<summary><strong>声音连接、格式与启动自动覆盖</strong></summary>

- 通过 root SSH 连接，默认地址为 `198.18.44.2:22`，在 `/run/instrument-workshop` 建立临时 bind mount。“修改 IP”和“探测 IP”并排显示，可手动输入或跨车内候选网段探测。探测仅检查 SSH 协议响应、不登录；发现后选择地址，再测试连接。端口固定 22；修改地址后清除旧连接记录并关闭自动覆盖，需重新连接、读取目录并手动启用。
- SSH 密码仅保留在界面内存中，不持久化；自动覆盖要求空密码登录。按配置的 IP 连接，不固定 SSH 主机密钥，CP 重启换密钥不会再次弹窗；这不能证明服务器身份，请在可信车内网络使用正确地址。仍校验 root 登录和原始资源摘要；不移除外部覆盖，也不将其识别为原声。
- 读取及覆盖前后核验获取新鲜 SHA-256 清单，复用本机摘要一致的不可变音频，仅下载缺失或变化资源；保留摘要检查与失败恢复。
- 可导入 MP4 音轨、MP3、M4A、AAC、Ogg、FLAC、Opus、AMR 和 WAV。本地 WAV 解析器支持 8/16/24/32-bit PCM、32/64-bit 浮点及受支持的 WAVEFORMATEXTENSIBLE 布局；其他编码使用 Android MediaCodec，兼容范围取决于车机解码器。输入 WAV 最大 32 MiB；输出统一为 48 kHz、16-bit PCM WAV，并匹配原声的单/双声道，最长 30 秒。不会自动复制原声时长或元数据；导出原声仍保留其容器元数据。
- CP 后台任务批量切换，使用序列锁防止并发，只重启受影响且原本运行的播放服务。失败时尝试恢复整组旧覆盖及服务状态；SSH 断线不自动重放结果不明的任务。
- ZIP 结构为 `manifest.json` 与 `audio/<sha256>.wav`。导入先检查路径、重复项、大小、版本、摘要、格式和声道，再替换本机规则。应用时再次核对 CP 原声摘要，拒绝不兼容预设。
- 自动恢复**默认关闭**。启用后，前台服务监听开机、快速启动、用户解锁/切到前台、接通电源、系统就绪及 STR 唤醒事件，应用进程启动也会触发检查；不会自动打开界面，监听服务空闲时不持有唤醒锁。
- 重复事件会合并，只读就绪检查采用有限退避，每轮最多等待 **3 分钟**，超时后亮屏期间仍每分钟检查。持久化系统任务每 15 分钟按系统调度补启监听，服务重建也会重新检查。必须已解锁 Android 用户、车机处于唤醒状态、CP 地址与目录一致、原声摘要匹配且无待核验分区写入任务。音效应用不再弹出额外驻车确认，也不依赖挡位属性。资源符合配置时不重复覆盖。结果不明的覆盖只做只读核对；若仍需修改，须手动应用后恢复自动执行。
- 安装后先打开应用一次，必要时在系统中允许后台运行；强制停止后需重新打开应用才能继续接收后台广播。不同系统的后台限制仍可能阻止自启动，自动恢复页会显示最近结果并提供后台设置入口。
- 静音规则也会随配置应用，启用自动覆盖前务必检查。旧版目录级声音覆盖需先在连接页还原，再读取新目录。

</details>

<details>
<summary><strong>存储、备份保护与任务进度</strong></summary>

镜像库位于**当前 Android 用户**的 `Documents/EVDashboard/`：

```text
images/       镜像与独立 JSON 记录
work/         生成中间文件，失败时保留
tasks/        写入任务清单与日志
deleted-*/    确认删除后的可恢复文件
```

- 源镜像不原地修改。生成约需额外 **4 GiB** 空间；写入在 `/data/local/evdashboard/jobs/<UUID>` 使用 root 专有暂存及全量回读，另需约 **2.25 GiB**，成功任务文件目前仍保留。
- 同设备、同 CP 槽、同固件基线的最后一份有效原始备份不能在应用内删除。原始分类不可降级；删除其他原始备份需两次确认。删除移入恢复目录，不立即释放空间。
- “原始”仅记录用户对来源的分类，不代表已鉴定为原厂固件。外部文件工具、root 或恢复出厂设置可能绕过保护，重要备份请另存到独立介质。
- 内置文件选择器支持本机及已挂载 U 盘，无需独立文件管理器；拒绝覆盖同名文件和写回受保护镜像库。镜像导入支持 `.img` / `.bin` 并执行结构检查。
- 完整导出采用 root 只读流、应用写文件并同步落盘，导出前后分区摘要必须与完整文件摘要一致。多用户路径后备方案核对实际用户及文件摘要。
- 任务卡显示当前操作及已用时间；可测步骤显示真实单步进度和有效剩余时间估计，其他步骤显示处理动画与计时。完成复制不等于任务成功，必须等全部检查结束。

</details>

## 从源码构建

需要 **JDK 17+**、**Android SDK 36** 和 **NDK 28.2.13676358**。当前原生构建脚本面向 macOS 主机，使用 `darwin-x86_64` NDK 工具链；其他平台需适配工具链路径。NDK 位于其他目录时，设置 `ANDROID_NDK_HOME`。首次构建需要获取 Gradle/Maven 依赖。

```sh
# 本机单测、Lint 与 Debug APK
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest

# 使用公开 AOSP testkey 的 Release APK 及仪器测试 APK
./gradlew -PinstrumentBuildType=release :app:assembleRelease :app:assembleReleaseAndroidTest
```

产物为 `app/build/outputs/apk/debug/app-debug.apk` 和 `app/build/outputs/apk/release/app-release.apk`。构建不会自动安装应用或连接车辆。

内置预设由 `tools/build-presets.py` 从声音实验室的套装生成到 `app/src/main/assets/presets/`。「荒野之息」预设（`presets/botw/`）包含第三方游戏音频，**刻意不纳入 git**；缺少它时应用照常构建，预设列表只显示 8bit 一套。

原生源码及构建输入位于 `native/` 与 `vendor/`。仪器测试应明确指定设备 serial、实际 Android 用户及测试类，不可在车辆上无差别运行。

第三方源码与许可见 [THIRD_PARTY.md](THIRD_PARTY.md)，许可证原文也随 APK 资产提供。再分发内置工具时，请履行对应源码及许可义务。
